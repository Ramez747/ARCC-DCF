# Discounted Cash Flow (DCF) Valuation Model — Arabian Cement Company (ARCC)

## Executive Summary
This repository contains a dynamic, 3-statement Discounted Cash Flow (DCF) valuation model for **Arabian Cement Company (ARCC)**, built in Excel. The model incorporates macro forecasts (inflation, foreign currency devaluation, GDP growth), detailed revenue and volume breakdowns (domestic vs. export cement & clinker), tax schedule adjustments, and a peer-group WACC analysis.

## Model Architecture & Key Features
- **3-Statement Model Integration:** Fully linked Income Statement, Balance Sheet items, and Working Capital schedules.
- **Macro Drivers:** Explicit scenario inputs for EGP currency devaluation, Egyptian inflation rates, and local lending/deposit rates.
- **Detailed Schedules:** Includes PP&E straight-line & tax depreciation schedules, debt schedules, and working capital cash flow adjustments.
- **WACC Calculation:** Peer group unlevered/relevered beta analysis (Sinai Cement, Misr Cement Qena, Misr Beni Suef) combined with Egyptian sovereign risk premiums.
- **Unlevered Free Cash Flow (FCFF):** Calculated using both the EBITDA and Net Income methods.

## Key Model Outputs
- **Calculated WACC:** 31.93% (reflecting local risk-free rates & country risk premium)
- **Terminal Growth Rate:** 5.0%
- **Implied Enterprise Value:** ~EGP 10.00 Billion
- **Implied Equity Value:** ~EGP 8.87 Billion
- **Implied Equity Value per Share:** ~EGP 23.65
